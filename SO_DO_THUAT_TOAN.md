📋 MỤC LỤC
----------
1. Thuật toán điều phối SOS tự động
2. Thuật toán cập nhật vị trí người dùng

1. THUẬT TOÁN ĐIỀU PHỐI SOS TỰ ĐỘNG
================================================================================

Khi người dùng gửi SOS, hệ thống tự động tìm và gán trạm phù hợp:

┌─────────────────────────────────────────────────────────────────┐
│                    NGƯỜI DÙNG GỬI SOS                          │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Nhận thông tin  │
                    │ SOS (loại, vị   │
                    │ trí, mức độ)    │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Xác định loại  │
                    │ trạm cần tìm:  │
                    │                │
                    │ Tai nạn/Y tế  │
                    │ → Trạm y tế    │
                    │                │
                    │ Hỏng xe/Khác   │
                    │ → Trạm cứu hộ  │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Tìm trạm sẵn   │
                    │ sàng (ready)   │
                    │ trong khu vực  │
                    └────────┬───────┘
                             │
                    ┌────────┴────────┐
                    │                   │
                    ▼                   ▼
          ┌─────────────────┐  ┌─────────────────┐
          │ Có trạm sẵn     │  │ Không có trạm  │
          │ sàng?           │  │ sẵn sàng       │
          └────────┬────────┘  └────────┬────────┘
                   │                    │
                   ▼                    ▼
          ┌─────────────────┐  ┌─────────────────┐
          │ Tìm trạm gần    │  │ Tìm trạm gần    │
          │ nhất trong     │  │ nhất trong     │
          │ danh sách sẵn  │  │ tất cả trạm    │
          │ sàng           │  │ (không sẵn)    │
          └────────┬────────┘  └────────┬────────┘
                   │                    │
                   └──────────┬─────────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Loại trừ trạm  │
                    │ đã từ chối     │
                    │ (rejected)     │
                    └────────┬───────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Tính khoảng    │
                    │ cách đến từng  │
                    │ trạm (Haversine)│
                    └────────┬───────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Sắp xếp theo   │
                    │ khoảng cách    │
                    │ (gần → xa)     │
                    └────────┬───────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Chọn trạm gần  │
                    │ nhất           │
                    └────────┬───────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Gán SOS cho     │
                    │ trạm (status:  │
                    │ pending)        │
                    └────────┬───────┘
                              │
                              ▼
                    ┌────────────────┐
                    │ Gửi thông báo  │
                    │ qua WebSocket  │
                    │ cho trạm       │
                    └────────────────┘

Lưu ý:
- Trạm sẵn sàng (ready) được ưu tiên hơn
- Trạm đã từ chối sẽ không được chọn lại
- Tự động chuyển sang trạm khác nếu trạm từ chối

3. THUẬT TOÁN TÌM TRẠM GẦN NHẤT
================================================================================

Tìm trạm gần nhất từ vị trí cho trước:

┌─────────────────────────────────────────────────────────────────┐
│                    TÌM TRẠM GẦN NHẤT                             │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Input:         │
                    │ - lat, lon     │
                    │ - loại SOS     │
                    │ - danh sách   │
                    │   trạm loại   │
                    │   trừ (nếu có) │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Lọc trạm theo  │
                    │ loại:          │
                    │                │
                    │ Tai nạn/Y tế   │
                    │ → medical      │
                    │                │
                    │ Hỏng xe/Khác   │
                    │ → rescue       │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Loại trừ trạm  │
                    │ đã từ chối     │
                    │ (nếu có)       │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Duyệt từng     │
                    │ trạm:          │
                    │                │
                    │ FOR mỗi trạm:  │
                    │   - Tính khoảng│
                    │     cách       │
                    │     (Haversine)│
                    │   - So sánh    │
                    │     với min    │
                    │   - Cập nhật   │
                    │     nếu gần hơn│
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Trả về trạm    │
                    │ gần nhất       │
                    │ (khoảng cách   │
                    │  nhỏ nhất)     │
                    └────────────────┘

Công thức Haversine (tính khoảng cách):
  distance = 2 * R * arcsin(√(a))
  
  Trong đó:
  - R = 6371 km (bán kính Trái Đất)
  - a = sin²(Δlat/2) + cos(lat1) * cos(lat2) * sin²(Δlon/2)
  - Δlat = lat2 - lat1
  - Δlon = lon2 - lon1

4. THUẬT TOÁN ROUTING (CHỈ ĐƯỜNG)
================================================================================

Tính toán đường đi từ điểm A đến điểm B:

┌─────────────────────────────────────────────────────────────────┐
│                    TÍNH TOÁN ROUTE                               │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Input:         │
                    │ - fromLat,     │
                    │   fromLon     │
                    │ - toLat,       │
                    │   toLon        │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Validate tọa   │
                    │ độ:            │
                    │                │
                    │ - lat: -90→90  │
                    │ - lon: -180→180│
                    └────────┬───────┘
                             │
                    ┌────────┴────────┐
                    │                   │
                    ▼                   ▼
          ┌─────────────────┐  ┌─────────────────┐
          │ Tọa độ hợp lệ?  │  │ Tọa độ không   │
          │ (YES)           │  │ hợp lệ (NO)    │
          └────────┬────────┘  └────────┬────────┘
                   │                    │
                   │                    ▼
                   │           ┌────────────────┐
                   │           │ Trả về lỗi    │
                   │           └────────────────┘
                   │
                   ▼
          ┌────────────────┐
          │ Gọi OSRM API:   │
          │                 │
          │ GET /route/v1/  │
          │ driving/        │
          │ {lon1},{lat1};  │
          │ {lon2},{lat2}   │
          └────────┬───────┘
                    │
          ┌─────────┴─────────┐
          │                    │
          ▼                    ▼
  ┌───────────────┐  ┌───────────────┐
  │ OSRM thành    │  │ OSRM thất bại │
  │ công?         │  │ hoặc timeout  │
  │ (YES)         │  │ (NO)          │
  └───────┬───────┘  └───────┬───────┘
          │                  │
          ▼                  ▼
  ┌───────────────┐  ┌───────────────┐
  │ Lấy geometry  │  │ Tạo route     │
  │ từ response   │  │ đơn giản      │
  │               │  │ (đường thẳng) │
  │ - coordinates │  │               │
  │   [lon, lat]  │  │ - 2 điểm:     │
  │               │  │   A → B       │
  └───────┬───────┘  └───────┬───────┘
          │                  │
          └──────────┬───────┘
                     │
                     ▼
          ┌────────────────┐
          │ Convert format:│
          │                │
          │ [lon, lat]     │
          │ → {lat, lon}   │
          └────────┬───────┘
                   │
                   ▼
          ┌────────────────┐
          │ Trả về polyline│
          │ (danh sách      │
          │  điểm)         │
          └────────────────┘

Lưu ý:
- OSRM trả về [lon, lat] nhưng frontend cần {lat, lon}
- Nếu OSRM lỗi, fallback về đường thẳng
- Timeout: 10 giây

┌─────────────────────────────────────────────────────────────────┐
│                    TRẠM NHẬN SOS                                │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐

                   │

  │ - assignedStationId│ - rejectedStationIds│

          │
          ▼
  ┌───────────────┐

  └───────────────┘

- Trạm chỉ thấy SOS phù hợp với loại trạm
- Từ chối sẽ tự động chuyển sang trạm khác
- Mỗi thay đổi trạng thái đều thông báo real-time

┌─────────────────────────────────────────────────────────────────┐
│                    KIỂM TRA HIỂN THỊ USER                        │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
                    ┌────────────────┐

                    │ SOS active:    │
                    │                │
                    │ - pending      │
                    │ - accepted     │
                    │ - on_route     │
                    └────────┬───────┘
                             │
                             ▼
                    ┌────────────────┐
                    │ Lấy danh sách  │
                    │ SOS đã hoàn   │

8. TỔNG KẾT
================================================================================

Các thuật toán chính:

1. ✅ Điều phối SOS tự động
   - Tìm trạm phù hợp
   - Ưu tiên trạm sẵn sàng
   - Tự động chuyển đổi

2. ✅ Cập nhật vị trí
   - Ưu tiên dữ liệu hardware
   - Tự động chuyển đổi nguồn
   - Real-time update

3. ✅ Tìm trạm gần nhất
   - Tính khoảng cách Haversine
   - Sắp xếp và chọn

4. ✅ Routing
   - Sử dụng OSRM
   - Fallback đường thẳng

5. ✅ ESP32 gửi dữ liệu
   - Định kỳ 30 giây
   - Tự động reconnect

6. ✅ Xử lý SOS trạm
   - Lọc theo loại
   - Cập nhật trạng thái

7. ✅ Bảo vệ quyền riêng tư
   - Ẩn vị trí sau khi xong
   - Chỉ hiển thị khi cần
